GPU Local LLM Hardware

คำนวณ Tokens/sec ก่อนซื้อ GPU — ไม่ให้ซื้อผิด

สูตรง่ายๆ ที่ใช้ทำนายความเร็ว LLM inference จาก spec hardware — bandwidth, wattage, overclock — สำหรับทั้ง NVIDIA GPU และ Apple Silicon Mac

1. สูตรเดียวที่ต้องรู้

Token generation (decode) ถูกจำกัดด้วย memory bandwidth ไม่ใช่ compute — ทุก token ใหม่ต้องอ่าน model weights ทั้งหมด 1 รอบ ดังนั้น:

Token Generation Rate
tokens/sec ≈ Memory Bandwidth (GB/s) ÷ Model Size (GB)
ความเร็วจริง = 50–70% ของค่านี้ (overhead จาก kernel launch, sampling, KV cache)

จบ. ถ้าจำได้แค่อย่างเดียวจากบทความนี้ จำสูตรนี้ ที่เหลือคือรายละเอียด

ตัวอย่างเร็ว

RTX 4090 (1008 GB/s) + 7B Q4 (~4 GB)
→ 1008 ÷ 4 = 252 tok/s (theoretical) → ~120-150 tok/s (real)

M2 Ultra (800 GB/s) + 7B Q4 (~4 GB)
→ 800 ÷ 4 = 200 tok/s (theoretical) → ~60-90 tok/s (real)

RTX 4060 Ti (288 GB/s) + 7B Q4 (~4 GB)
→ 288 ÷ 4 = 72 tok/s (theoretical) → ~35-50 tok/s (real)
Rule of thumb: เอา bandwidth ÷ ขนาด model (GB) = tok/s ceiling แล้ว × 0.5–0.7 ได้ค่าจริง ใช้ได้ทั้ง NVIDIA และ Apple Silicon

3. Overclock — อันไหนช่วยจริง

GPU Core Overclock — ❌ แทบไม่ช่วย decode

Decode ถูกจำกัดด้วย memory — GPU core นั่งรอ weights มา Core OC จาก 2.5 → 2.8 GHz ได้ประมาณ 2–5% เท่านั้น ไม่คุ้มกับความร้อนและความเสี่ยง

VRAM Memory Overclock — ✅ ช่วยจริง

OC memory clock ตรงๆ เพิ่ม bandwidth ได้ 10% = ได้ ~7–10% tok/s — นี่คือ overclock เดียวที่มีผลกับ inference

ตัวอย่าง RTX 4090:
Stock:       21 Gbps → 1008 GB/s → ~130 tok/s
+10% mem OC: 23.1 Gbps → 1108 GB/s → ~143 tok/s (+10%)

GPU core OC: +200 MHz → ได้แค่ ~3% (noise)

Apple Silicon — ❌ OC ไม่ได้

Bandwidth ถูก fix โดย SoC design ไม่มี knob ให้ปรับ — ซื้อมาเท่าไหร่ได้เท่านั้น จริงๆ แล้วเป็น feature — ไม่ต้อง tune เสถียร

อย่าซื้อ GPU เพราะ overclock headroom — ซื้อจาก stock bandwidth 10% ที่ได้จาก mem OC เป็น bonus ไม่ใช่เหตุผลเลือก GPU

5. Checklist ก่อนซื้อ

  • ☐ ตั้งเป้า tok/sChat: 20+ พอ | Batch: 50+ | Real-time agent: 100+
  • ☐ เลือกขนาด model7B Q4 = ~4GB | 13B Q4 = ~7GB | 70B Q4 = ~40GB
  • ☐ คำนวณ: bandwidth ÷ model size = tok/s ceilingใช้สูตรข้างบน ค่าจริง = 50-70%
  • ☐ เช็ค VRAM/UMA ใส่ model ได้7B ต้อง 4GB | 13B ต้อง 7GB | 70B ต้อง 40GB+
  • ☐ คำนวณ perf/watttok/s ÷ TDP — ถ้ารัน 24/7 ค่าไฟสำคัญ Mac ชนะ
  • ☐ เช็คราคาต่อ bandwidthRTX 3090 มือสอง: ~33 GB/s/พันบาท | 4090: ~18 | M2 Ultra: ~6
  • ☐ อย่าดู core clockMemory bandwidth สำคัญกว่า — GPU ช้าแต่ VRAM เร็ว ชนะ GPU เร็วแต่ VRAM ช้า

6. ข้อผิดพลาดที่พบบ่อย

เข้าใจผิดทำไมผิดควรทำอย่างไร
"ต้องการ CUDA cores เยอะ"Decode ถูกจำกัดด้วย bandwidth ไม่ใช่ computeดู memory bandwidth แทน
"OC แล้วจะเร็วขึ้น"Core OC ได้ ~3% — มีแค่ mem OC ที่ช่วยซื้อจาก stock bandwidth
"8GB VRAM พอ"7B Q4 แทบไม่พอ 13B ไม่ได้เลย16GB ขั้นต่ำ, 24GB ใช้สบาย
"Mac ช้าสำหรับ AI"M2 Ultra มี 800 GB/s — เร็วกว่า GPU ส่วนใหญ่เทียบ bandwidth ไม่ใช่ "GPU vs Mac"
"cloud API คุ้มกว่า"รายเดือนสะสม — ซื้อ hardware ครั้งเดียวจบคำนวณ: ราคา GPU ÷ ค่า API ต่อเดือน = เดือนคืนทุน

สรุป

tok/s = Bandwidth (GB/s) ÷ Model Size (GB)
ค่าจริง × 0.5–0.7

นั่นคือ 80% ของสิ่งที่ต้องรู้ ที่เหลือ:

→ Memory bandwidth คือ spec เดียวที่สำคัญสำหรับ decode
→ Mem OC ช่วย ~10% Core OC ไม่ช่วย
→ Mac ชนะ perf/watt NVIDIA ชนะ raw speed และ ecosystem
→ VRAM size กำหนดว่ารัน model ไหนได้
→ RTX 3090 มือสอง คุ้มสุดในแง่ bandwidth ต่อราคา
