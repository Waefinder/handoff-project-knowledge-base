📋 Detailed Step-by-Step (แต่ละจุดอย่างละเอียด)

Step 1: User → MS Teams
ผู้ใช้พิมพ์ข้อความ / แนบไฟล์ ใน Teams chat
ActionData
พิมพ์ข้อความactivity.text = "ช่วยตรวจข้อ 3"
แนบ Excelactivity.attachments[] + downloadUrl
แนบ Videoactivity.attachments[] + content_type: video/mp4
แนบ Imageactivity.attachments[] + content_type: image/jpeg
💡 Teams จะ serialize ทุกอย่างเป็น Activity JSON แล้วส่งไป Azure Bot Service
Step 2: MS Teams → Azure Bot Service
Azure Bot Service รับ Activity → route ไป registered endpoint

Azure Bot Service ทำ 3 อย่าง:

  1. Authenticate — ใช้ App ID + Secret ขอ token จาก Bot Framework
  2. Route — ส่ง HTTPS POST ไปยัง registered messaging endpoint
  3. Manage connections — จัดการ conversation references, activity IDs
# Azure Bot Service ส่ง HTTP POST ไปยัง registered endpoint: POST https://abc123.ngrok-free.app/api/messages Authorization: Bearer <bot-framework-token> Content-Type: application/json { "type": "message", "text": "ช่วยตรวจข้อ 3", "from": { "id": "user-id", "name": "Chavagorn" }, "conversation": { "id": "conv-id-xxx" }, "attachments": [...] }
Step 3: Azure Bot → ngrok Tunnel → localhost:8000
Tunnel forward HTTPS request เข้ามาที่เครื่อง local
# ngrok สร้าง public HTTPS URL ที่ forward ไป localhost:8000 Public: https://abc123.ngrok-free.app ↓ (HTTPS tunnel) Local: http://localhost:8000 ← FastAPI server # Flow: Azure Bot ──HTTPS──→ ngrok cloud ──tunnel──→ localhost:8000/api/messages
⚠️ Firewall Point: ถ้า company firewall block outbound port → tunnel ใช้ไม่ได้ ต้องใช้ Cloudflare Tunnel (ใช้ port 443/HTTPS เท่านั้น)
Step 4: FastAPI รับ Request
app.py รับ Activity → Authenticate → Extract message + attachments

Step 5: FastAPI → Hermes CLI (subprocess)
เรียก hermes -p pe-bot -z "prompt" ผ่าน subprocess
# Build full prompt จาก 4 sources: full_prompt = learnings + audit_register + history_context + user_message # Invoke Hermes cmd = ["hermes", "-p", "pe-bot", "-z", full_prompt] process = subprocess.run(cmd, capture_output=True, text=True) reply_text = process.stdout.strip() # Hermes response

⚠️ Pitfalls & Lessons Learned

ปัญหาที่เจอบ่อย + วิธีแก้ — จากประสบการณ์จริง

🔴 Critical Pitfalls

❌ Azure Portal Blocked by Company IT
ไม่สามารถ register bot หรือ update endpoint ใน Azure Portal ได้

ปัญหา: Company IT block Azure Portal access — ไม่สามารถสร้าง Bot resource หรือ update messaging endpoint

Workaround:

  • ใช้ personal Microsoft account register bot
  • ใช้ developer tenant (ฟรี)
  • ลอง Power Automate แทน (company มัก enable ไว้)
❌ ngrok URL Changes Every Restart
Free ngrok ให้ URL ใหม่ทุกครั้ง — ต้อง update Azure Bot endpoint

Solution:

  • Cloudflare Tunnel — URL คงที่, ฟรี
  • ngrok paid plan — static domain
  • Script auto-update Azure endpoint (ต้องมี Azure access)
❌ openpyxl Destroy Excel Formatting
openpyxl ลบ shapes, images, cell styles ตอน save

Solution: ใช้ shutil.copy2 คัดลอกต้นฉบับก่อน → แล้วใช้ win32com (COM automation) edit

# ✅ วิธีที่ work: shutil.copy2(template, output) # preserve 100% excel = win32com.client.Dispatch("Excel.Application") wb = excel.Workbooks.Open(output) # edit cells... wb.Save()
❌ -z Flag Creates New Session Every Time
zero-shot mode ไม่เก็บ history — ต้อง inject เอง

Problem: hermes -z สร้าง session ใหม่ทุกครั้ง — conversation history หาย

Solution: เก็บ history ใน JSON file แล้ว inject เข้า prompt ทุกครั้ง

# ✅ External history management history = conversation_history.load_history(conv_id) history_text = format_history_for_prompt(history) full_prompt = history_text + "\n\n" + user_msg cmd = ["hermes", "-p", "pe-bot", "-z", full_prompt]
❌ COM Initialization Error in FastAPI Threads
win32com fail เมื่อเรียกจาก async thread
# ❌ Error: CoInitialize has not been called # ✅ Fix: Initialize COM ใน worker thread import pythoncom def com_worker(): pythoncom.CoInitialize() # ← ต้องเรียกก่อน try: # win32com operations... finally: pythoncom.CoUninitialize() # ← cleanup
❌ LM Studio Not Running → Bot Hang Forever
ถ้า local AI ไม่ running — subprocess ไม่มี timeout → hang
# ✅ Health check ก่อน start: curl http://localhost:1234/v1/models # ✅ Fallback provider: # ~/.hermes/profiles/pe-bot/config.yaml fallback_providers: - model: gemini-3.1-flash-lite provider: gemini # cloud fallback
