📦 GGUF Format

File format สำหรับ local LLM — รวม weights + metadata ในไฟล์เดียว ใช้กับ llama.cpp, LM Studio, Ollama

# ตัวอย่าง GGUF model files Qwen3-8B-Q4_K_M.gguf ← 4-bit quantized, ~5GB Llama-3-8B-Q8_0.gguf ← 8-bit quantized, ~8.5GB Mistral-7B-F16.gguf ← 16-bit full precision, ~14GB # ดาวน์โหลดจาก: # - HuggingFace (hf.co) # - LM Studio (built-in model browser) # - Ollama (ollama.com)

⚖️ Local vs Cloud — ข้อดี-ข้อเสีย

✅ Local AI (LM Studio / Ollama)

  • Free — ไม่เสียค่า API ใช้ได้ตลอด
  • Privacy — ข้อมูลไม่ออกจากเครื่อง
  • Offline — ใช้ได้แม้ไม่มี internet
  • Fast inference — ถ้ามี GPU แรง
  • Customizable — fine-tune ได้ตามต้องการ

❌ Local AI — ข้อจำกัด

  • Hardware cost — ต้องมี GPU ดี (RTX 3090+)
  • Quality gap — 7B/8B ยังสู้ GPT-4 ไม่ได้
  • Memory hungry — 70B ต้องมี 40GB+ VRAM
  • No latest models — ต้องรอมี quantized version
  • Setup complexity — ต้อง config หลายอย่าง

☁️ Cloud AI (Xiaomi MiMo, OpenAI, etc.)

  • Best quality — access to largest models
  • No hardware needed — ใช้ได้ทันที
  • Always updated — model ใหม่เข้าถึงทันที
  • Scalable — ไม่ต้องกังวลเรื่อง RAM
  • Simple setup — แค่มี API key

⚠️ Cloud AI — ข้อจำกัด

  • Cost — เสียเงินรายเดือน/ต่อ token
  • Privacy risk — ข้อมูลส่งไป server ภายนอก
  • Internet required — ใช้ไม่ได้ถ้า offline
  • Rate limits — อาจถูก limit ตอนใช้เยอะ
  • Vendor lock-in — ย้าย provider ยาก

🏭 Setup ที่ใช้จริงใน Ampas Industries

Current Setup: Hermes Agent (Desktop) + Xiaomi MiMo v2.5 (Cloud) + Custom MCP Servers (Excel + PowerPoint) + LM Studio (Backup/Local testing)

Decision flow ที่ใช้:

  • เดิม: ใช้ LM Studio (local) ทั้งหมด → ฟรี แต่ quality ไม่พอสำหรับ complex tasks
  • ปัจจุบัน: สลับมา Xiaomi MiMo cloud → เสีย ~$16/mo แต่ quality ดีขึ้นมาก
  • Fallback: ถ้า cloud ล่ม → fallback ไป Gemini Flash Lite (free tier)
fallback_providers: - model: gemini-3.1-flash-lite provider: gemini # → Free fallback เมื่อ primary provider ไม่ available

Why this matters: สำหรับบริษัทที่มี budget จำกัด — ต้อง balance ระหว่าง quality, cost, และ privacy Local models ดีสำหรับ sensitive data แต่ cloud models ดีกว่าสำหรับ complex reasoning
